# SCRIPTORIUM

A native Windows application for organizing personal media libraries.

## Vision

Scriptorium is a local-first media organizer for tutorials, TV shows, movies and other personal media.

The application indexes media without modifying the original files, allowing users to browse, search and track their library through a modern interface.

## Goals

- Organize media regardless of type.
- Keep metadata separate from media files.
- Preserve the original folder structure.
- Provide a beautiful browsing experience.
- Resume playback and reading progress.
- Remain fast with very large libraries.

## Current Scope

Supported media:

- Tutorials
- TV Shows
- Movies

## Core Features

- Import folders
- Scan media
- Generate library
- Search & Filter
- Categories
- Favorites
- Progress tracking
- Resume playback
